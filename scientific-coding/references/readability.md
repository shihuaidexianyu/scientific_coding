# 写法、中文说明与格式

用于业务、编排和检查辅助函数。读者掌握 Python 基础语法，应能沿执行顺序
看懂输入如何变成输出；节省 token 不是代码优化目标。

## 顺序表达数据变化

- 筛选、转换、聚合、路径选择和输出构造分别命名，再交给后续步骤。
  名称说明实际含义；简单常量不必变成无意义临时变量。
- 默认使用简单赋值、if/elif/else、for。一个循环完成一项操作，复杂步骤
  拆成有具体用途的函数；不能为减少重复增加泛化框架或细碎跳转。
- 推导式最多一个 for、一个简单 if；这只是上限，不是默认风格。嵌套推导、
  条件推导、复杂短路、三元选择、lambda/map/filter 或调用链不用于压缩步骤。
  显式循环可含一个简单判断；更深 for/if 拆开，elif 属于并列分支。
- 科学 API 如 NumPy reduction、矩阵乘法和成熟统计函数可以保留，说明输入、
  轴和输出即可，不重写成缓慢手工循环。重构保留数值顺序、随机抽样、阈值
  边界、零/空值含义和迭代器惰性，不为命名结果强制全量载入数据。
- 所有源码与配置物理行至多 80 个 Unicode 字符，含缩进和注释。按语义拆行，
  不改字符串值或路径。Markdown 正文不受此限，其中代码正例受限。

## 中文说明出现在使用处

**文件头：** Python 开引号独占一行，下一行写用途，再给真实字符流程图。
说明本文件处理的文件或内存对象、实际读写方法、字段/轴与单位、输出和
关联 TOML；只计算的模块明确不读取配置、不写文件。不要把调用方的读写
误说成本文件行为，也不能用一张总图代替各函数和局部说明。

**函数：** 每个函数使用可被语言服务读取的中文 docstring，作为首条语句。
按“用途 → 参数 → 返回 → 处理过程 → 副作用”排列。每个参数或返回成员
以 `name : type` 单独一行，下一行缩进解释，成员之间空一行。
具体写字段、嵌套键、数组轴、类型、单位、默认值、路径基准和必要假设；
不能只写 dict/array 或“见另一个函数”。同型映射说明键和值的结构及意义。
处理步骤分行；无参数或返回值时简述，不制造虚假字段。

函数文档必须与当前函数一致，不能把声明的假设说成已验证；路径说明对应
实际解析方式。修改错误说明时不改变正确实现去迎合它。语言服务可用时
检查调用处真实 hover；只解析 docstring 时注明没有验证编辑器显示效果。
不为塞进 hover 首屏删除必要内容。固定排版见
[stage_header.md](../templates/stage_header.md)。

**语义块：** 导入、一个循环或几行共同完成一项操作可共用中文注释，
重要科学选择、分支、样本和轴变化在附近解释，不逐行翻译标点。
注释块前空一行，块后紧贴代码，连续注释不拆开；函数 docstring 后的首个
注释块也要空行。文件首行、shebang、编码和必要指令保持原有位置。
不写挤在语句末尾的解释性注释。

**TOML：** 每节、每键前写中文注释并留块前空行，解释作用、单位、端点、
选项和路径基准。查看并完善本次修改关联的配置说明，即使参数值未变化。
科学依据未知时如实说明，值不因补注释而改变。

**数据：** 在实验 MD、函数与结果说明的适当位置交代初始输入和每步产物：
位置/格式/编码、字段或轴、单位与缺失值、样本 ID 和顺序、具体读取方式、
变换增加或删除了什么。排除留逐 ID 原因，拆分/聚合留映射及权重。
使用实际适用的信息，未知项不编造；无需默认建立独立契约文件体系。

## agent 的格式脚本与最终阅读

为本次语言编写并运行小型脚本：用 tokenizer/parser 或适用词法方式识别
真实注释块，保护多行字符串、字符串中的 # 和必要指令；修正缺失空行，
报告最终超长行。语义表达式由作者改写，不机械截断字符串。

用小反例验证：缺空行应检出，连续注释不拆开，字符串内容不变，Python
覆盖 docstring 后首注释；行宽区分 80 与 81。编辑结束后核对最终文件，
用 AST/解析值及相关测试确认含义不变。脚本只属作者工具，不进入流水线。

再沿一个样本和主要中间变量顺序阅读：需要在脑中拆开几个操作或补出中间
变量时继续改写。核对注释和真实行为一致，例如分组不保证等长、更多重采样
不保证更窄区间。结构/格式通过不能代替这种阅读；无新变化不重复无关测试。
